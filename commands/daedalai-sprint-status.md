---

Invoke the `daedalai-sprint-status` skill with the sprint label the
user provided (e.g. `DAEDAL-104a`) or a sprint publicId. If no
argument is given, the skill defaults to the current ACTIVE sprint
on the current project.

Arguments: $ARGUMENTS
